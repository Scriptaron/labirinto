# Guia Completo de JavaScript

JavaScript é uma das linguagens de programação mais populares do mundo.

## O que você vai aprender

- Fundamentos da linguagem
- Programação assíncrona
- Manipulação do DOM
- ES6+ features

## Por que aprender JavaScript?

JavaScript é essencial para desenvolvimento web moderno. Com ele você pode:

1. Criar sites interativos
2. Desenvolver aplicações web
3. Programar no backend com Node.js
4. Criar aplicativos mobile com React Native

Vamos começar!
